# CRUD Operations Django
#Sample project to learn CRUD in django

A simple CRUD (Create, Read, Update, Delete) application built using Django.

## Features
- Create records
- View records
- Update records
- Delete records

## Technologies Used
- Python
- Django
- SQLite

## Run Locally

git clone <repo-url>

cd Crud-operations-Django

pip install -r requirements.txt

python manage.py runserver
